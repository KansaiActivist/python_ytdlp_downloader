# python_ytdlp_downloader
Pythonを使用し軽量で簡単にYouTube動画をダウンロードする。単一ファイルのみ使用。
## セットアップ
### Pythonをインストールされていない方
Pythonを必須で使用します。[ここから](https://www.python.org/downloads/ "ダウンロードページ")ダウンロードを行ってください。
### インストールしている方
ytdlpとffmpegをインストールされていない方はSetup（Windows ```setup.bat``` Mac ```setup.sh``` Linuxの場合テキストファイルにインストール方法を入力しています）を実行してください。自動でインストールされます。
すでにされている方や上記の手順を終えた方は```run.bat```または```run.sh```を実行またはターミナルで``` python youtube_downloader.py ```を実行してください。GUIが起動します。
