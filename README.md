# python_ytdlp_downloader
Pythonを使用し軽量で簡単にYouTube動画をダウンロードする。単一ファイルのみ使用。ワンクリック機能は現状Windowsしか対応していません。
## セットアップ
### Pythonをインストールされていない方
Pythonを必須で使用します。[ここから](https://www.python.org/downloads/ "ダウンロードページ")ダウンロードを行ってください。
### インストールしている方
ytdlpとffmpegをインストールされていない方はsetup.batを実行してください。自動でインストールされます。
すでにされている方や上記の手順を終えた方はdownload.batを実行またはターミナルで``` python youtube_downloader.py ```を実行してください。GUIが起動します。
